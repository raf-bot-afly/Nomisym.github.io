Guía de Instalación

Instrucciones paso a paso para instalar y configurar NomiSys en tu equipo

Antes de Comenzar

Sigue esta guía para instalar NomiSys correctamente en tu sistema. Asegúrate de cumplir con los requisitos mínimos antes de proceder con la instalación.

Requisitos del Sistema

Sistema Operativo

Windows 10 o superior

Memoria RAM

Mínimo 4 GB (recomendado 8 GB)

Espacio en Disco

500 MB libres

Java Runtime Environment

Versión 8 o superior

Proceso de Instalación

1

Descargar el Instalador

Visita la página de descargas y haz clic en "Descargar Ahora" para obtener el instalador de NomiSys.

Nota: El archivo de instalación tiene aproximadamente 85 MB.

2

Ejecutar el Instalador

Localiza el archivo descargado (NomiSys_V1.0.0.exe) y haz doble clic para ejecutarlo.

Nota: Si aparece una advertencia de seguridad, haz clic en "Ejecutar" para continuar.

3

Seguir el Asistente de Instalación

El asistente te guiará a través del proceso de instalación:

  • Acepta los términos de licencia
  • Selecciona la carpeta de destino (recomendado mantener la predeterminada)
  • Elige los componentes a instalar
  • Confirma la instalación
4

Completar la Instalación

Una vez finalizada la instalación, puedes optar por ejecutar NomiSys inmediatamente. El programa creará un acceso directo en tu escritorio y menú de inicio.

Implementación Inicial

Configuración después de la Instalación

Una vez instalado NomiSys, es importante realizar la configuración inicial para adaptar el sistema a las necesidades de tu empresa:

Definición de Períodos de Nómina

Establece la periodicidad de pago (semanal, quincenal, mensual) en "Configuración > Períodos de Nómina".

Configuración de Conceptos de Pago

Define los conceptos de percepciones y deducciones que aplicarás en las nóminas.

Registro de Empleados

Agrega la información de tus empleados en la sección "Empleados > Registro".

Nota: Para una implementación más detallada, consulta el Manual de Usuario o contacta a nuestro equipo de soporte.

Solución de Problemas Comunes

Error: Java Runtime Environment

Descarga e instala la versión más reciente de Java Runtime Environment desde el sitio oficial.

El instalador no se ejecuta

Verifica que el archivo se haya descargado completamente. Intenta desactivar temporalmente tu antivirus durante la instalación.

Problemas de permisos

Ejecuta el instalador como administrador (clic derecho > Ejecutar como administrador).
